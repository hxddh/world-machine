# Roadmap

The plan is World Machine 1.0, "A finished harbour": seven slices, P0 to P7, from a clean base to launch. It is written in [REVIEW_v0.30.md](REVIEW_v0.30.md), under "The plan: v1.0" and "What 'finished' means for World Machine 1.0", with the owner's decisions and answers. Tiny Society is the 1.0 product.

- **Now: P0, a clean base.** No compatibility with any v0.x version or record. There is a 1.0 save contract ([SAVES.md](SAVES.md)), the sitting ledger lives in the World file, and the documents are current. CI is to run under 15 minutes, the nightly is to be green, and the largest files are to be split.
- **What is not done yet** is in [KNOWN_ISSUES.md](KNOWN_ISSUES.md); what shipped is in the [changelog](../CHANGELOG.md).
- **The kernel's rules** are in [AGENTS.md](../AGENTS.md) and [ARCHITECTURE.md](../ARCHITECTURE.md).

The reviews of v0.6 to v0.28 and the plans they set are kept in [archive/](archive/) for their history; the roadmap before 1.0 is in git history. Neither directs the work any more.
