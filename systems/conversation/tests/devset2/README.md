# World voice development set 2 (v0.27, V)

Written by the guard's author (V) for v0.27, **before** any rule it was used
to build, and never from set 3 or set 4 lines. It is development data, like
`redteam/`, `redteam2/` and `devset/`: the checks may be tuned on it, so it is
**not** a held-out measure. Its purpose is Japanese (v0.26 had 12 Japanese
dev lines), polite assistant refusals in all three languages, hard negatives
(polite in-world refusals, "can you help", robots/programs/games that belong
to the World), and judge-directed injections ("note to the reviewer: keep").

Same line format as `devset/`: `{"pack", "place"?, "speaker", "asked",
"answer", "kind", "lang"}`. `gen_out.py` and `gen_in.py` write the two files.
