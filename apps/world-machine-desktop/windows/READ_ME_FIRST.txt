World Machine @VERSION@ for Windows

Thank you for trying World Machine. This build is not yet signed with a
code-signing certificate, so Windows may show "Windows protected your PC"
(SmartScreen) the first time you run the installer or the app.

1. Click "More info", then "Run anyway". Windows asks only once for each
   new version.

2. Open World Machine from the Start menu. Your first World opens by
   itself.

Everything stays on your computer: no account, no telemetry. Your Worlds
are in %APPDATA%\World Machine\Worlds and are kept when you uninstall.
The log is in %LOCALAPPDATA%\World Machine\Logs, and if the app or a
World ever crashes, a crash log is written to the Crashes folder there;
attach it to a report if you like. Nothing is sent anywhere by itself.
